# Esgii Studio: IB Business Management review games

Two phone-friendly review games for IB DP Business Management (current guide, first assessment 2024), units 1.1-1.6 and 3.1-3.4. The teacher narrates from a board deck; students play on their own devices.

| Game | Focus | Address |
|---|---|---|
| The Founder's Journey | Paper 1 style | https://cnwizda.github.io/ib-bm-review/founders-journey/ |
| The Numbers Room | Paper 2 style | https://cnwizda.github.io/ib-bm-review/numbers-room/ |

Start page: https://cnwizda.github.io/ib-bm-review/

Each game is a single self-contained HTML file (no server, no tracking). Progress is saved in the student's own browser. All businesses, people and figures are fictional.

Photos are CC BY 2.0 or public domain (via Openverse); credits are in each game's menu.
